bot-template — live demo

A generic polling bot: poll a source, dedupe what it already saw, alert on what's new. This page simulates a poll cycle in your browser — one item is already in the seen-set, so it gets skipped. The /api/health endpoint runs the same logic on the server.

Repo: github.com/JelfferyDuran/bot-template

Polling + dedupe + alerts + multi-server config. Python stdlib only. No tokens, no accounts — the demo runs on fake data.
